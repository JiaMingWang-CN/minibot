# minibot 标志使用规范

## 理念
一只眼睁着，另一只眨成光标下划线：友好的小 bot，在你自己的电脑上干活。

## 构成
- 头部：184 × 144 圆角矩形，圆角半径 52（画布 256）。
- 圆眼：直径 40；光标眼：46 × 18 横条，底边与圆眼底边对齐。
- 文字标 `minibot`：定制几何字形（路径，无字体依赖），x 高 100、笔画 22、上伸部 140；圆形字母上下各超出 1.5 作视觉补偿。

## 颜色
| 名称 | HEX | RGB | CMYK（近似） | 说明 |
|---|---|---|---|---|
| minibot 紫 | `#7C3AED` | 124 58 237 | 48 76 0 7 | 主色，与界面强调色一致；白底对比度约 5.7:1 |
| 墨色 | `#1C1917` | 28 25 23 | 0 11 18 89 | 文字标、正文 |
| 白 | `#FFFFFF` | 255 255 255 | 0 0 0 0 | 反白版本 |

CMYK 为直接换算值，印刷前请用色卡校对；Pantone 可参考 266 C，需实物比对。

## 留白与最小尺寸
- 四周留白 ≥ 圆眼直径（符号高度的 28%）。
- 符号最小 16px；24px 及以下改用 `minibot-symbol-small.svg`。
- 横排组合最小宽度 96px，再小时只用符号。

## 允许的背景
白、浅暖灰（stone-50 至 stone-200）用紫色版；紫色、深色（stone-800 及更深）用反白版；照片上只在平整、低对比区域使用反白版。

## 禁止
- 改变两只眼的形状或左右位置（右眼必须是横条，竖条会读成电源开关符号）。
- 拉伸、旋转、加描边、阴影、渐变。
- 用其他字体重排 `minibot` 文字标。
- 改变符号与文字标的比例和间距。
