# minibot 设计语言

> 全局 UI 规范。以后新增或修改任何界面，都以本文为准；本文没覆盖的情况，取最接近的已有 token 与组件，不临时发明新值。

## 0. 来源与改编原则

本规范以 **DeepSeek Harness（dsh）桌面端** 的设计系统为蓝本整理，取自本机安装包 `@deepseek-ai/dsh-client-ui-theme`（`--dsw-*` token、字号阶梯、圆角、阴影/elevation、动效、焦点）与 `dsh-web-frontend` 的组件样式（按钮、输入框、开关、菜单、对话框、Toast、Tag、侧栏、composer、气泡）。

照搬的部分：三层 token 架构、偏蓝的中性灰阶、黑/白主按钮、0.5px 发丝描边 + 极淡阴影的层级表达、圆角尺度与超椭圆圆角、字号阶梯、动效时长与缓动、焦点环规则、组件尺寸。

**唯一的改编：强调色。** dsh 的「业务强调色」是 DeepSeek 蓝（`#4176E6`），用于焦点环、链接、光标、选中强调、用户气泡底色。minibot 的品牌色是紫 `#7C3AED`（见 `docs/brand/使用规范.md`），所以这些位置一律换成 minibot 紫阶。其余颜色（中性灰、状态色）保持 dsh 原值。

minibot 自己的品牌元素保留：logo（眨眼 bot，右眼为光标横条）和文字标都用 `docs/brand/` 里的 SVG，不引入 dsh 的 Montserrat 品牌字体。

## 1. 设计原则

1. **内容在前，界面退后。** 大面积是白（浅色）或近黑（深色）的中性底，界面框架只用灰阶表达；颜色只留给状态和交互反馈。
2. **主操作用黑白，不用彩色。** 主按钮在浅色模式是近黑底白字，深色模式反过来。品牌紫不做大面积填充，只出现在：焦点环、链接、输入光标、选中强调、用户气泡的淡底、logo。
3. **层级靠发丝和光，不靠边框。** 浮起的表面（菜单、对话框、composer、卡片）用 0.5px 发丝描边 + 两层极淡阴影，不画 1px 实线边框。同一平面内的分隔用半透明黑（`border-l1`~`l4`），不用实色灰线。
4. **密度适中，字号克制。** 界面正文 14px，次要文字 13/12px，标题最大 24px。字重只用 400/500/600/700，界面强调一律 500。
5. **圆角成体系。** 只用 6 档圆角（4/8/12/16/20/28），按组件层级选，支持时圆角走超椭圆。
6. **动效短而安静。** 100/200/300ms 三档，标准缓动 `cubic-bezier(.4,0,.2,1)`；只在回应用户操作或表达状态变化时使用；尊重「减少动态效果」。
7. **一套 token，两套主题。** 组件只引用语义 token，浅色/深色只在 token 层切换。

## 2. Token 架构

三层，前缀 `--mb-`：

| 层 | 命名 | 作用 | 谁能用 |
|---|---|---|---|
| static（原始色阶） | `--mb-static-<色系>-<档>` | 调色板本身，只存色值 | 只有 alias 层引用 |
| alias（语义） | `--mb-alias-<用途>` | 「主文字」「一级描边」「悬停底」等语义 | 所有组件 |
| specific（组件专用） | `--mb-specific-<组件>` | 侧栏底、气泡、菜单材质等只有一个组件用的值 | 对应组件 |

规则：

- **组件 CSS 里不出现裸色值**（`#xxx`、`rgb()`），一律 `var(--mb-alias-*)` / `var(--mb-specific-*)`。
- 缺值时先用最接近的语义 token；确需新值，在同一次改动里同时加一档 static 和一个 alias，不能只加一边。
- 深色主题挂在 `body[data-theme="dark"]` 上只重定义 alias/specific；static 两套相同。
- 尺寸类 token（圆角、字号、阴影、时长）不分主题。

### 3.4 用色规则

- 一屏内彩色只有：强调紫（交互反馈）+ 当前需要的状态色。不为装饰加彩色、渐变或彩色阴影。
- 文字对比度：正文 ≥ 4.5:1，大字/图标 ≥ 3:1。`label-tertiary` 只用于辅助信息，不用于必须读懂的内容。
- 错误 / 警告 / 成功都是「淡底 + 同色系文字或图标」，不用实色大块。
- 选区：`color-mix(in srgb, #3B82F6 40%, transparent)`（沿用 dsh）。

## 4. 字体

### 4.1 字体栈

```css
--mb-font-text: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
  "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif;
--mb-font-code: "SF Mono", "JetBrains Mono", "Fira Code", Consolas, "Liberation Mono", Menlo, Courier,
  "PingFang SC", "Microsoft YaHei";
```

- 只用系统字体，不加载网络字体（应用离线运行，且服务端 CSP 为 `default-src 'self'`）。
- 品牌字样只用 `docs/brand/` 的 SVG 文字标，不用任何字体重排 `minibot`。
- 数字列、计数、步骤号用 `font-variant-numeric: tabular-nums`。
- 不调字间距（`letter-spacing` 保持默认），不用全大写标签。

## 5. 圆角

| token | 值 | 用于 |
|---|---|---|
| `radius-xs` | 4px | 键帽、极小标记 |
| `radius-sm` | 8px | 小按钮（28px 高）、图标按钮、Tooltip、tab、紧凑列表项 |
| `radius-md` | 12px | 常规按钮（36px 高）、输入框、菜单项、列表行 |
| `radius-lg` | 16px | 卡片、代码块、Toast、悬浮卡 |
| `radius-xl` | 20px | 用户消息气泡 |
| `radius-panel` | 28px | 对话框、composer 卡片、大面板 |
| 胶囊 | 999px | Tag、Pill、开关、状态点 |

规则：

- 外层圆角 ≥ 内层圆角；嵌套时内层 = 外层 − 内边距，取最近一档。
- 圆角平滑：在 `@supports (corner-shape: superellipse(1.5))` 内对所有元素启用超椭圆；正圆和胶囊必须同时声明 `corner-shape: round`，否则会被压扁。

## 6. 描边、阴影与层级

### 6.1 发丝描边

浮起表面的轮廓用阴影画 0.5px 发丝线，不占布局、不用 `border`：

```css
--mb-elevation-stroke: 0 0 0 .5px var(--mb-elevation-stroke-color); /* 默认 border-l3，深色 border-l4 */
```

### 6.2 Elevation（描边 + 两层极淡柔光）

| token | 值 | 用于 |
|---|---|---|
| `elevation-panel` | stroke, `0 3px 8px #00000008`, `0 0 16px #00000005` | 卡片、侧面板 |
| `elevation-prominent` | stroke, `0 3px 8px #0000000A`, `0 0 20px #0000000D` | 对话框、菜单 |
| `elevation-soft` | stroke, `0 4px 16px #00000008`, `0 0 24px #00000008` | composer（专用，模糊更大、更淡） |

用了 elevation 的表面设 `border: 0`。

### 6.3 阴影阶（无描边的场合）

| token | 值 | 用于 |
|---|---|---|
| `shadow-lv1` | `0 2px 4px #0000000D` | 轻微浮起 |
| `shadow-lv2` | `0 4px 12px #00000005, 0 2px 8px #0000000A` | 悬浮按钮 |
| `shadow-lv3` | `0 0 1px #00000033, 0 0 4px #00000005, 0 12px 32px #00000014` | Toast、悬浮卡 |

### 6.4 材质

- 菜单：`background: var(--mb-specific-menu); backdrop-filter: blur(40px) saturate(150%);` 浅色描边 `border-l1`，深色 `border-l3`。
- 模态遮罩：`bg-mask-1` 半透明黑，**不模糊**背景。

### 6.5 层级（z-index）

| 层 | z-index |
|---|---|
| 页内吸顶 | 10–30 |
| 菜单 / 下拉 | 70 |
| Tooltip / 悬浮卡 | 100 |
| 模态对话框 | 1000 |
| Toast | 1100 |

## 7. 间距与布局

### 7.1 间距

4px 基准网格，常用档：2、4、6、8、10、12、14、16、20、24、32。组件内用 4–12，区块间用 16–24，页面边距 24–32。

### 7.2 应用骨架

```
┌──────────────┬──────────────────────────────────────────┐
│ 侧栏          │ 主区（bg-base）                            │
│ sidebar-fill │   ┌── 内容列 ≤ 920px，居中 ──┐              │
│ 内边距 6×8   │   │ 消息流                    │              │
│ 行高 34/30   │   └──────────────────────────┘              │
│              │   ┌── composer 卡片 ≤ 内容列+32 ──┐         │
│              │   │ radius-panel · elevation-soft │         │
│              │   └───────────────────────────────┘         │
└──────────────┴──────────────────────────────────────────┘
```

- **标题栏**：32px，颜色与下方表面一致（现有 `titleBarOverlay` 机制）。
- **侧栏**：底 `sidebar-fill`，内边距 `6px 8px`，正文 14px；行左右内边距 12px，图标与文字间距 6px；常规行最小高 34px，密集 30px，紧凑 24px；选中行 `sidebar-item-active`，悬停 `interactive-hover`；行圆角 `radius-md`。侧栏滚动条在指针离开时透明。
- **主区**：底 `bg-base`，与侧栏之间不画分隔线，靠底色差区分。
- **内容列**：`width: min(calc(100% - 32px), 920px)`，宽屏时可用 `clamp(680px, 64%, 920px)`。
- **composer**：卡片最大宽 = 内容列 + 32px，两侧留白 16px（窄窗 8px），底部 4px；卡片 `radius-panel`、`elevation-soft`、底 `input-major`；输入区最小高 36px、最大高 336px，字号 `max(16px, 正文字号)`，内边距 `4px 8px 0 14px`，光标色 `state-accent`。
- **设置 / 记忆等二级页**：同一骨架，内容放在设置卡片里（底 `settings-card-fill`，描边 `settings-card-stroke`，`radius-lg`）。

### 7.3 响应

- 宽度 ≤ 767px：表单行改为纵向（标题、说明、输入框依次排列），输入框占满宽。
- 粗指针设备：输入框字号 16px。
- 所有页面在窗口最小尺寸下无横向滚动。

## 8. 动效

| token | 值 |
|---|---|
| `duration-fast` | 100ms：悬停、颜色、透明度 |
| `duration` | 200ms：对话框、遮罩、展开 |
| `duration-slow` | 300ms：面板滑入、较大位移 |
| `ease` | `cubic-bezier(.4, 0, .2, 1)`（标准缓动） |

各组件的固定动效：

| 场景 | 动效 |
|---|---|
| 对话框 + 遮罩 | 淡入，200ms，标准缓动 |
| 菜单 | 淡入 / 淡出 |
| Tooltip | 淡入 150ms |
| Toast | 进入 160ms ease-out（自上方 6px 落下 + 淡入），停留 3s，1s 淡出 |
| 开关滑块 | `transform` 120ms ease |
| 加载 spinner | 旋转 0.8s linear 循环，2px 环 + 72° 强调弧 |
| 运行中文字 | 扫光（shimmer），叠加色浅色 30% 黑 / 深色 45% 白 |
| 状态点 | 运行中旋转虚线弧 |

规则：

- 动效只回应用户操作或表达状态变化，不做无目的的入场动画。
- 只动 `opacity` 和 `transform`（高度过渡除外）。
- `prefers-reduced-motion: reduce` 下：对话框、遮罩、面板动画全部关闭；Toast 只保留淡出；循环动画停止。

## 9. 焦点与可访问性

- **焦点环**：所有可聚焦元素 `:focus-visible` 时显示 2px 轮廓，颜色 `state-accent`；密集表格、工具栏可用 1px。`outline-offset` 由组件定（开关、复选框为 2px）。
- **指针 / 键盘模态**：鼠标点击后不显示焦点环（可编辑文本框除外，点击后保留自己的聚焦样式）；键盘操作时恢复。实现方式：在 `html` 上记录 `data-input-modality`，指针模态下把焦点环颜色设为透明，不清除 `box-shadow`。
- **最小点击区**：图标按钮 28×28；行内交互元素高度 ≥ 24px。
- **禁用态**：透明度 0.4，`cursor: not-allowed`（列表项 / 开关可用 0.5 + `cursor: default`）。
- 图标按钮必须有 `aria-label` 与 `title`；状态不只靠颜色表达（配图标或文字）。

## 10. 组件规范

尺寸均为浅色/深色通用，颜色写语义 token 名（省略 `--mb-alias-` 前缀）。

### 10.1 按钮 Button

| 属性 | md（默认） | sm |
|---|---|---|
| 高度 | 36px | 28px |
| 水平内边距 | 14px | 10px |
| 字号 | 14 / 22 | 12 / 18 |
| 圆角 | `radius-md` | `radius-sm` |
| 图标 | 16px，与文字间距 4px | 同左 |

变体：

| 变体 | 常态 | 悬停 | 用途 |
|---|---|---|---|
| primary | 底 `button-primary-fill`，字 `label-foreground` | `button-primary-hover` | 每个区域最多一个主操作 |
| ghost | 透明，字 `label-primary` | `interactive-hover`；按下 `interactive-active` | 次要操作、工具栏 |
| outline | 透明 + 内嵌发丝描边 `border-l3` | `interactive-hover` | 并列的次要操作（如「取消」） |
| toolbar | `button-toolbar-fill` | `button-toolbar-hover` | 覆盖在图片/媒体上 |
| danger | ghost 形态，字 `state-error` | `interactive-hover-danger` | 删除等破坏性操作 |

- 悬停样式放在 `@media (hover: hover)` 内。
- 按钮文字说清动作（「保存」「批准」「删除供应商」），不用「确定」「提交」这种泛词。

### 10.2 图标按钮 IconButton

28×28，内边距 6px，图标 15–16px，`radius-sm`，色 `label-secondary`，悬停 `interactive-hover`，禁用 0.4。图标统一 24 网格、2px 描边、圆头圆角、`currentColor`。

### 10.3 输入框 Input / Textarea / Select

| 属性 | 值 |
|---|---|
| 高度 | 34px（textarea 自适应） |
| 内边距 | `0 12px` |
| 描边 | 0.5px `border-l4` |
| 圆角 | `radius-md` |
| 底 | `bg-layer-3` |
| 字号 | 13px，行高 1.5 |
| placeholder | `label-dimmed` |
| 聚焦 | 描边变 `state-accent`，不加外发光 |
| 错误 `aria-invalid` | 描边 `state-error`，下方 12px 错误说明 |
| 禁用 | 字 `label-tertiary` |

- 表单标签 13px/500 `label-primary`，与输入框间距 6px；说明文字 12px `label-tertiary`。
- Select 用自绘下拉箭头（同源 SVG 文件，不用 `data:` URI）。

### 10.4 开关 Switch

轨道 36×20、内边距 2px、胶囊；关：轨道 `border-l3`，滑块 `switch-thumb`；开：轨道 `button-primary-fill`（黑/白，不用紫），滑块 `label-foreground`，右移 16px，过渡 120ms。

### 10.5 复选框 Checkbox

16×16 原生框，`accent-color: button-primary-fill`；标签 14/20，间距 6px。

### 10.6 标签 Tag / Pill

- **Tag**：胶囊，内边距 `1px 8px`，11/17，字重 500。语气：`outline`（发丝描边 `border-l4` + `label-tertiary`）、`neutral`（`bg-module-platform` + `label-secondary`）、`solid`（`label-primary` 底 + `bg-layer-3` 字）、`quiet`（只有 `label-tertiary` 字）、`success` / `warn` / `error`（状态色 10% 底 + 状态色字）。
- **Pill**（可点的筛选/提及）：高 24px，内边距 `0 8px`，12/18，底 `bg-layer-2`，字 `label-secondary`，图标间距 4px。

### 10.7 菜单 Menu

- 容器：内边距 4px，最小宽 96px，`specific-menu` 毛玻璃 + `elevation-prominent`，圆角 `radius-lg`。
- 菜单项：最小高 34px（密集 30px、紧凑 24px），内边距 `6px 8px`，图标间距 6px，13/20，`radius-md`；悬停/键盘焦点 `interactive-hover`；危险项 `state-error` + `interactive-hover-danger`；禁用 0.4。
- 菜单图标色：浅色 bluish-800，深色同 `label-primary`。
- 分组头吸顶时用 `specific-menu-group-header`。

### 10.8 Tooltip

底 `tooltip-bg`，白字，13/20，内边距 `3px 7px`，`radius-sm`，最大宽 50vw，淡入 150ms，不拦截指针。带快捷键时附键帽：16×16、`radius-xs`、`tooltip-key-bg`，11/14。

### 10.9 Toast

顶部居中（距顶 40px），宽度随内容、最大 640px；内边距 `12px 16px`，`radius-lg`，底 `toast-bg`，字 `toast-label` 14/22，`shadow-lv3`；左侧状态图标（警告 `state-warn-label`，成功 `state-success`），可带一个内联操作链接（violet-400）。停留 3s 后淡出。错误不用 Toast 静默消失——需要用户处理的错误放在页内。

### 10.10 对话框 Dialog

- 宽 `min(380px, 100%)`，`radius-panel`，底 `bg-layer-2`，`elevation-prominent`，`border: 0`。
- 结构与间距：头部 `22px 14px 12px 24px`（标题 16/24/500 + 右侧 28×28 关闭按钮）→ 说明 14/22，左右 24px → 内容区上 20px、左右 24px → 底部按钮右对齐、间距 8px、下 24px。
- 遮罩 `bg-mask-1`；进入淡入 200ms；Esc 和点击遮罩关闭（有未保存内容时除外）。
- 破坏性确认：主按钮写明后果（「删除」），放在最右。

### 10.11 卡片 Card / 设置卡片

底 `settings-card-fill`，发丝描边 `settings-card-stroke`（或 `elevation-panel`），`radius-lg`，内边距 16–20px。卡片内行与行之间用 `border-l1` 分隔线，不嵌套卡片。

### 10.12 对话消息

- **用户消息**：右对齐，气泡底 `specific-bubble`，`radius-xl`，内边距 `10px 16px`，正文字号，`pre-wrap`。
- **bot 消息**：无气泡，直接排在内容列里，Markdown 阶梯排版；头部是 bot 头像 + 名字（13px/600）。
- **思考过程**：可折叠，默认收起；展开后左侧 2px `border-l2` 竖线、`label-tertiary` 字；收起时下沿用渐隐遮罩（浅色白→透明，深色 bluish-950→透明）。
- **工具调用 / 结果**：可折叠行，标题 13px，展开后是代码块样式（`code-block` 底、`radius-lg`、11/16 等宽）；运行中标题用扫光动效。
- **系统提示**：居中小号文字，`label-tertiary`。
- **流式输出**：末尾显示品牌光标（logo 右眼的横条形状，`state-accent` 色，1s 步进闪烁）。
- 消息之间间距 20–24px。

### 10.13 审批卡片

底 `state-warn-tertiary`，左侧 3px `state-warn` 竖条，`radius-lg`；标题 14/500，工具名用等宽字体，操作摘要 13px；右侧按钮：「批准」primary sm、「拒绝」outline sm。已处理后整卡降为 `bg-module-platform` 底、透明度 0.6，并写明结果。

### 10.14 代码块

底 `code-block`，`radius-lg`，上下外边距 16px；标题条（语言名 + 复制按钮）内边距 `9px 14px`，底 `code-block-banner`，13px；代码区内边距 `6px 22px 20px`，11/19 等宽；默认换行，可切换不换行。行内代码底 `inline-code`，12px 等宽，圆角 `radius-xs`，内边距 `0 4px`。

### 10.15 Tab

高 28px，内边距 `0 10px`，13px，`radius-sm`，最小宽 80、最大宽 170；常态 `label-secondary`，悬停 `interactive-hover`，激活 `label-primary` + `markdown-tag` 底；关闭按钮只在激活/悬停时出现，标题右端渐隐。

### 10.16 加载与空状态

- **Spinner**：20×20，2px `border-l2` 环 + 72° `button-primary-fill` 弧，0.8s 旋转。
- **骨架屏**：`bg-skeleton` 块，圆角同目标元素，块间距 10px，透明度脉冲。
- **空状态**：居中；插画或 logo（≤ 56px）+ 标题 `font-l-20` + 一句说明 `label-tertiary` + 可选一个主操作。文案说明「现在可以做什么」，不写「暂无数据」。

### 10.17 滚动条

WebKit 伪元素：宽 5px，滑块 `scrollbar-thumb`，悬停 `scrollbar-thumb-hover`，轨道透明；浮层内换用 l2 档；侧栏在指针离开时滑块透明。

## 11. 图标与插画

- 产品图标：24 网格、2px 描边、圆端圆角、单色 `currentColor`，常用 15/16/18px。
- 品牌图形：只用 `docs/brand/` 的 SVG；24px 以下用 `minibot-symbol-small.svg`（≈ `favicon.svg`）。
- 插画（空状态、引导）：分层平面，使用 `illustration-*` 灰阶（浅色背景 bluish-55、前层 bluish-90、后层/细节 bluish-310；深色前层比后层亮），不加渐变和投影。
- 所有图形以内联 SVG 或同源文件提供；服务端 CSP 为 `default-src 'self'`，**禁止 `data:` URI 图片和外链资源**。

---

## 12. 文案

- 用用户的词，不用系统内部的词（「模型服务」而不是 provider config）。
- 按钮写动作，动作在整个流程里同名（按钮「保存」→ 提示「已保存」）。
- 错误说明发生了什么、怎么修，不道歉、不含糊。
- 空状态是行动邀请，不是情绪表达。
- 简体中文，句子格式，不加多余的感叹号和省略号；中英文之间加空格。

## 13. 与当前实现的差距（迁移清单）

当前界面（`apps/desktop/static/assets/style.css`）还没按本规范实现，主要差异：

| 方面 | 现状 | 规范 |
|---|---|---|
| 灰阶 | 暖灰 stone（`#f5f5f4`、`#e7e5e4`、`#78716c`） | 冷调 neutral-bluish |
| 主按钮 | 紫底白字 | 黑底白字（深色反转）；紫只做强调 |
| 描边 | 1px 实色 `#e7e5e4` / `#d6d3d1` | 0.5px 半透明 `border-l*`；浮层用 elevation |
| 圆角 | 8/9/10/12/14/16 混用 | 4/8/12/16/20/28 六档 |
| 焦点 | 紫色 3px 外发光 | 2px `state-accent` 轮廓环，指针模态隐藏 |
| 输入框 | 38px 高、1px 实线 | 34px 高、0.5px `border-l4`、`bg-layer-3` |
| 字号 | 15px 根字号，标题 22px | 界面 14px 阶梯，标题按 4.2 表 |
| 主题 | 只有浅色 | 浅色 + 深色，token 层切换 |
| token 命名 | `--violet`、`--ink`、`--line` 等少量变量 | `--mb-static-*` / `--mb-alias-*` / `--mb-specific-*` |

建议落地顺序：先建 `tokens.css`（static + alias + specific，两套主题）→ 替换全局基础样式（按钮、输入框、焦点、滚动条）→ 按页面迁移（引导页 → 对话 → 设置 → 记忆）→ 最后接入深色模式切换。
